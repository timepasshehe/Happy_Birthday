# Happy Birthday 🎂

A warm, responsive birthday greeting website with a hand-built cake illustration, interactive candles, and a confetti celebration.

## Preview

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Customize

- Change the headline and birthday wish in `index.html`.
- Adjust the colors, layout, and cake illustration in `style.css`.
- Update the celebration effects in `script.js`.

The site uses plain HTML, CSS, and JavaScript, so there is no build step. Google Fonts are loaded from the web; system serif and sans-serif fonts are used if they are unavailable.
